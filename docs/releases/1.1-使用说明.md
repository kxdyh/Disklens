# DiskLens 1.1

官网：[disklens.site](https://disklens.site/)；问题反馈：[GitHub Issues](https://github.com/kxdyh/Disklens/issues)。

## 中文与英文

在“设置 → 外观与交互 → 语言”选择中文或 English，选择会保存并应用到主界面、其他任务与弹窗。文件名、路径、卷标和输入保留原文。官网导航栏提供独立语言切换；英文使用说明见同包 `UserGuide.en.md`。

新 AI 分析同时返回中文简短用途、中文详细分析及对应英文。切换语言直接读取已保存译文，不会额外请求模型。旧个人记录缺英文时会提示需要重新分析；新双语提示词改变缓存上下文，实际请求前仍需确认。每批数量是上限，应用也按输出预算拆批，双语输出当前最多每批 15 项。

## 安装与升级

支持 64 位 Windows 10 和 11，已内置运行环境。运行从官网下载的 Windows x64 安装包并选择安装位置。DiskLens 启动时申请管理员权限以读取更多目录，无法访问的项目会列入扫描报告。

1.1 系列会提示更高版本，用户可前往官网下载并覆盖安装；1.0 需要手动升级。覆盖安装和卸载均保留用户设置、API Key、个人分析缓存和共享管理凭据。

## 共享经验（Beta）

默认关闭，可从主界面常驻入口或设置进入说明和协议流程，同意未来合格贡献并成功保存后才开启；历史贡献单独选择。关闭窗口不等于同意。

默认服务为 `https://api.disklens.site/`，旧官方地址导出的管理凭据可继续导入。Beta 服务需要联网，可能限流或暂停；只有符合匹配条件且已发布的经验才会返回。

开启后，扫描完成或重启恢复时优先匹配公共云端经验，其次使用有效个人历史。云端结论完整读回并显示后，可清理相同路径的重复个人缓存。用途未知、文字不完整、尚未持久入队或期间新产生的个人结果保留。

云端匹配先下载公开的脱敏路径索引，然后在本地检查扫描结果，对命中的规范化特征去重并分批获取结论。此流程与 AI 分析的文件大小阈值无关。点击「重新匹配云端经验」可刷新当前打开区域；AI 分析前会统计可复用结果，实际提交模型仍需确认。取消不会把未完成项目当作成功。

所选范围内达到阈值的普通及受保护文件、目录均可分析，用途分析不替代删除保护。公共云端复用受公共身份、角色、结构、来源和置信度约束，不保证任意同名项目都能命中。可共享受控软件标识、路径角色、适用版本、结构、用途/建议，以及通过过滤的中英文简短用途和详细分析；不上传文件正文、API Key、完整私人路径或原始扫描清单。自由文本过滤不能保证绝对匿名。

不共享清单覆盖目录、子内容及父摘要中的相关结构。增加排除项会取消不再符合条件的待发送记录。贡献可查看、单项或全部撤回；停用只停止今后使用，已上传内容可另行撤回。管理凭据用当前 Windows 账户加密，可显式导出恢复文件，需自行妥善保管。官方新旧域名视为同一服务，旧官方地址导出的恢复文件仍可导入；更换为其他服务不会沿用同意或凭据，旧本机隔离测试文档保留。

符合隐私规则、用途已知且为中或高置信度的合格分析可以贡献并供他人匹配。安装标识不代表独立真人，云端结果也不保证结论正确。分析完成后，合格贡献自动入队；失败重试不调用模型。

贡献上传队列尚未清空时，窗口左下角会持续加粗提示尽量不要关闭应用，并保留上传进度和失败状态；队列清空后提示消失。关闭应用不会主动删除已持久保存的待上传队列，再次开启共享后可继续处理。

已清理重复个人缓存的条目，之后离线重启时不再有该条本地备份；需要联网重新读取云端结论。

## 个人 AI 与缓存

AI 分析由用户主动启动，向自行配置的模型服务发送文件元数据，服务商按其规则收费。自动刷新不会自动发起付费分析。支持分析扫描根目录或当前目录、进度、用时、取消及实际 API Token 用量。

分析指令内置于应用，随程序版本更新，不提供模板展示或编辑入口，安装包与 ZIP 不附带独立提示词文件。升级后旧版旁置的自定义模板不再生效；应用统一使用内置指令，与旧自定义模板不一致的缓存会在下次分析时重新生成。

个人缓存按原始分析时间保留 30 天，命中不续期；最多 20,000 条或 32 MiB，完整请求上下文参与失效。相同并发请求会合并、按实际请求归属费用；设置提供占用查询与清理，清理个人缓存不撤回共享贡献。

文件外部变更会合并同步，无权限或断开的目录保留原记录。应用打开后会检查官网版本信息，不会自动下载安装，可关闭或忽略某一版本。

**AI 与共享经验仅供参考。删除前请确认用途并备份重要数据；应用不会自动删除文件，移入回收站仍需用户确认。**
