# DiskLens 1.1 user guide

[Website](https://disklens.site/) · [Report an issue](https://github.com/kxdyh/Disklens/issues)

## Installation and language

DiskLens supports 64-bit Windows 10 and 11 and includes its runtime. Run the Windows x64 installer from the website. DiskLens requests administrator permission to read more directories; inaccessible items appear in the scan report.

Choose Chinese or English under **Settings > Appearance and interaction > Language**. Your choice is saved and applies across the application. File names, paths, volume labels, and your input remain unchanged. The download website has its own language selector.

The 1.1 series can notify you of newer versions. Version 1.0 needs a manual update from the website.

Moving items to the Recycle Bin uses the Windows system flow. Windows handles progress, files in use, permissions and confirmation when an item cannot fit in the Recycle Bin. DiskLens does not delete files automatically.

## Scanning and browsing

Select a drive or folder for each task. Up to three scans can run at once. Click a block to select it and double-click a folder to open it after the scan completes. Back goes up one level; Home returns to the current scan root. Each level initially shows the largest 50 items, with the remainder available on further pages. External file changes are merged automatically.

The scan report distinguishes recognized file allocation from the volume's used space and unassigned differences. Administrator permission does not guarantee access to every protected location. A difference is not a list of disposable files.

## Optional AI analysis

Configure your model service and API key. Your provider determines charges. Analysis starts only when you request it and confirm the actual submission list. It sends file metadata rather than file contents. Select the scan root or current folder; the default threshold is 512 MiB. Eligible files and folders within that scope can be analyzed, including protected locations. Deletion protections remain independent.

New results contain a short purpose and detailed analysis in both Chinese and English. Switching language reads stored translations and does not call the model again. Older personal results without English show a translation-unavailable message; reanalyze explicitly to generate both languages. The new built-in prompt changes the cache context, and paid requests still require confirmation.

Prompts are embedded in the application. There is no prompt editor or separate template file in the package. Your batch-size setting is an upper bound; output and token budgets can split it further. Bilingual requests currently contain at most 15 items per batch. Insufficient output budget stops further requests instead of treating unfinished items as successful.

Personal results remain valid for 30 days from their original analysis time. Reuse does not renew this period. The cache is bounded to 20,000 entries or 32 MiB. Clearing it does not withdraw shared contributions. Automatic file refresh does not start paid AI analysis.

## File purpose experience sharing (beta)

Sharing is off by default. Open its introduction from the main window or settings. A five-second reading countdown below the agreement unlocks its consent checkbox without requiring scrolling to the bottom. Explicitly consent to the agreement and future eligible contributions. Historical sharing is a separate option. Activation is shown only after the service confirms it and settings are saved.

The default service is `https://api.disklens.site/`. Recovery files exported for the former official address remain compatible. The beta service requires internet access and may be rate limited or unavailable.

When enabled, DiskLens queries anonymized fingerprints in batches. Eligible new AI conclusions enter a persistent upload queue automatically, without another contribution confirmation. Shared data can include controlled public software identity, path roles, structure, categories, confidence, filtered Chinese and English purpose text, and necessary consent and receipt information. File contents, API keys, complete private paths, and raw scan lists are not uploaded. Text filtering does not guarantee absolute anonymity.

Failed contribution uploads remain saved locally and retry in the background at one-minute intervals, up to three times, stopping when complete. Only lower-left status messages appear, without progress bars or blocking other operations. Closing the app does not intentionally remove the persistent queue or reset its used retries. Failed cloud matching still requires a manual retry.

DiskLens checks the public cloud library first and fills unresolved paths from valid personal history. Duplicate personal entries can be cleared after a complete, known-purpose cloud answer is retrieved and displayed. Unknown, incomplete, newer and not yet durably queued results are retained.

DiskLens downloads a privacy filtered path index and checks scan results locally. It groups matching normalized fingerprints and retrieves conclusions in batches. The file size threshold applies to paid AI analysis only. Use Rematch cloud experience to refresh the open area. The AI confirmation screen separates items that can reuse an answer from items that need a model call. Canceling does not mark unfinished items as successful.

Eligible Medium or High confidence conclusions with known purposes can be shared and reused. Privacy rules still apply; arbitrary files with the same name do not necessarily match. An installation identity does not prove an independent person, and model confidence does not prove deletion safety.

Excluded folders cover their descendants and related parent summaries. Disabling sharing stops queries and uploads and hides shared results; previously uploaded contributions require a separate withdrawal. Recovery files contain management credentials and must remain private. Background retries do not call the model again.

After a duplicate personal entry has been removed, an offline restart has no local backup of that entry. Reconnect to retrieve its cloud conclusion again.

## Updates and removal

Update checks offer a link to the official website; they do not download or install software automatically. You can dismiss or ignore a version. Uninstalling removes application files and shortcuts while preserving your settings, API key, cache, and sharing credentials.
