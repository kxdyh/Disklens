# DiskLens 安装器

安装器沿用固定 AppId，升级时默认复用原安装目录和安装范围，合并原卸载记录。

1.1.5 的“移入回收站”使用 Windows 系统流程，由系统显示进度、占用、权限和超限时的永久删除确认。不同项目仍可并行处理；应用只在系统确认完成后更新视图。

安装成功后自动清理两类内容：

- 安装目录内，旧组件清单有记录、新清单已不再包含且 SHA-256 未变化的程序文件。更换安装目录时，也会清理同一安装记录对应的旧目录中可确认归属的组件。没有旧清单的历史安装，只按 `legacy-components.json` 内已知发行文件的哈希处理。
- 原用户的下载目录，以及当前安装包所在目录顶层的旧版 `DiskLens-Setup-版本-x64.exe`。同时核对文件名版本、PE 文件版本、发布者和产品描述；支持浏览器添加的 `(1)` 等重复编号。

当前安装包、同版或更高版本安装包、测试包、未知文件、用户配置、密钥和分析数据会保留。不会递归清空目录，也不会运行旧卸载器。占用、权限不足、重解析路径或无法核实归属的项目会跳过。取消或安装失败时不执行删除。

`Cleanup.ps1` 由安装器临时解压，通过 Windows PowerShell 5.1 隐藏执行。安装文件在当前安装权限下清理，下载包使用启动安装器的用户身份清理。结果写入标准 Inno Setup 安装日志；无法执行清理不影响新版本安装成功。

## 构建

先生成包含运行环境的 Windows x64 发布目录，再运行：

```powershell
.\Build-Installer.ps1 -PublishDirectory <发布目录> -OutputDirectory <输出目录> -Version 1.1.5 -IconFile <DiskLens.ico>
```

发布目录须包含 `DiskLens.App.exe`、`LICENSE`、`使用说明.md`、`UserGuide.en.md`、`NOTICE.md`、`THIRD-PARTY-NOTICES.txt`。构建脚本会核对应用版本、生成组件清单、编译安装包，并生成 SHA-256 校验文件。脚本仅生成安装包；官网和 GitHub 发行页另提供免安装 ZIP。不发布 PDB、私有控制台或管理凭据。
