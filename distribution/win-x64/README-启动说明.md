# DiskLens Windows 预览版

构建日期：2026-11-06；源码版本：ea80630。

## 启动

1. 退出正在运行的旧版 DiskLens。
2. 将整个 DiskLens 文件夹解压到空间充足的位置。
3. 双击 DiskLens.App.exe，按系统提示确认管理员权限。

此包包含运行环境，无需另外安装 .NET。已有设置、模型连接和分析缓存继续使用原本的用户数据位置；压缩包不含用户 API 密钥、源码或调试符号。

## 功能与更新

- Home 首页及独立扫描标签，最多同时扫描 3 个位置，其余排队。
- 进度与主题色条按已扫描的去重磁盘占用 / 扫描开始时所在卷已用空间计算。done 表示所选位置遍历完成，不代表找到了磁盘的每一字节。
- 普通与全屏视图均提供返回上一级、回到扫描根目录及扫描报告入口。
- 扫描报告列出具体读取问题及原因；整盘扫描单列 Windows 系统预留，说明剩余差额。
- 改进附加数据流的占用统计，读取错误按路径去重。
- 设置中收起的下拉框不再随鼠标滚轮误切换，滚轮继续滚动设置页面。
- 每层展示最大的 50 项，“其余”可继续分页浏览；支持日间、夜间等主题。
- AI 分析可选 DeepSeek 或自定义 OpenAI 兼容接口，由用户配置并主动触发。

快捷键：Ctrl+T 新扫描，Ctrl+Tab 切换任务，Ctrl+W 关闭任务，Ctrl+1 首页，Ctrl+Home 回到当前扫描根目录。

文件夹扫描的进度同样以所在磁盘已用空间为分母。系统预留、NTFS 元数据、受限目录以及扫描期间的空间变化可能导致文件占用与 Windows 已用空间存在差额；报告不会把此差额伪装为可删除的文件。
