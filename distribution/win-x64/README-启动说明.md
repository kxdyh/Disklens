# DiskLens 1.1.5 · Windows x64 启动说明

发布日期：2026-11-28。适用于 Windows 10 / 11 x64。

本目录保留启动说明。可运行的安装包和免安装 ZIP 请从 [1.1.5 发行页](https://github.com/kxdyh/Disklens/releases/tag/v1.1.5)或[官网](https://disklens.site/#download)下载；仓库自动生成的源码压缩包需自行构建。

## 安装与启动

1. 退出正在运行的 DiskLens。
2. 使用安装包时，运行 [DiskLens-Setup-1.1.5-x64.exe](https://disklens.site/#download)，完成安装后从快捷方式启动。
3. 使用免安装 ZIP `DiskLens-1.1.5-win-x64.zip` 时，将整个文件夹完整解压到空间充足的位置，再双击 `DiskLens.App.exe`。请保留同目录内的依赖文件。
4. 如 Windows 显示权限确认，请核实程序来源后再继续。

官方 Windows x64 发行包包含运行环境，无需另外安装 .NET。升级后继续使用原有用户数据位置中的设置、模型连接和分析缓存。普通发行包不附带用户 API 密钥或运营管理凭据。

## 扫描、分析与云端经验

- 扫描在本机进行，可同时运行最多 3 个扫描任务，通过顶部标签切换。
- 双击文件夹块进入下一层，通过上一级、扫描根目录和扫描报告入口继续浏览；支持浅色、深色及全屏专注视图。
- `done` 表示所选位置已遍历完成。进度以扫描开始时所在磁盘已用空间为分母；系统预留、NTFS 元数据、受限目录和扫描期间的变化，可能使完成时的文件占用与磁盘已用空间存在差额。
- AI 分析为可选功能，需要在设置中配置自己的服务地址、模型和 API Key，并主动发起分析。服务商可能单独收费。
- 云端经验共享默认关闭，启用前请阅读功能协议和共享范围；匹配成功的项目会显示相应结论。
- 协议页通过 5 秒阅读倒计时解锁首个同意框，无需滚动到底，仍需由你明确勾选。
- 云端经验上传失败后，每隔 1 分钟在后台重试，最多 3 次；仅在左下角显示状态，不出现加载条。
- 云端连接沿用已交付桌面版的实现：首次直连候选探测、连接复用及网络变化后重选；本次同步相应公开源码。

快捷键：`Ctrl+T` 新扫描，`Ctrl+Tab` 切换任务，`Ctrl+W` 关闭任务，`Ctrl+1` 首页，`Ctrl+Home` 回到当前扫描根目录。

## 手动回收规则

`ProgramData`、`Program Files`、`Windows` 及其子路径不再因为所在位置被应用整体禁止手动回收。文件块右键菜单、文件详情和分析列表采用同一套规则。

磁盘或网络共享根目录、聚合显示的伪块，以及扫描、AI 分析或刷新期间仍不能回收。点击“移入回收站”直接调用 Windows 系统删除流程，由系统显示进度、占用、权限、重试和超限时的永久删除确认。应用只在系统确认完成后更新视图。

DiskLens 不会自动删除文件。位置风险和 AI 分析结论仅供参考；能够手动回收不代表适合删除。操作前请核实文件用途，备份重要资料。
