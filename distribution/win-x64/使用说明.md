# DiskLens 1.1

官网：[disklens.site](https://disklens.site/)；问题反馈：[GitHub Issues](https://github.com/kxdyh/Disklens/issues)。

## 安装与升级

支持 Windows 10 / 11 64 位，已内置运行环境，无需另装 .NET。运行 `DiskLens-Setup-1.1.0-x64.exe`，选择安装位置；也可完整解压 ZIP，运行 `DiskLens/DiskLens.App.exe`。启动应用需要管理员授权，以读取更多磁盘目录，无法访问的内容会列入扫描报告。

本次新增共享经验及缓存加固仍归入 1.1.0。此前已安装 1.1.0 的用户需要手动下载新版并覆盖安装；更新检查只提示更高版本，同号不会提示。1.0 用户也需要从官网手动升级。覆盖安装和卸载均不删除用户设置、API Key、个人分析缓存或共享管理凭据。

## 共享经验（Beta）

默认关闭，每个应用版本最多推荐一次，可随时从设置进入。阅读协议、选择同意未来贡献、预览共享范围后才开启；历史贡献单独选择。关闭窗口不等于同意。

默认服务：`https://disklens-shared-beta-v11.disklens-shared-knowledge-beta.workers.dev/`。这是独立在线 Beta，真实经验仍在积累，当前没有已验证的真实成熟共识；服务可能限流或暂停，没有合格共识就返回未命中。测试覆盖数据不代表真实用户或实际磁盘覆盖率。

开启后，先使用本地保护与有效个人历史，再查询在线共享经验，未命中可继续个人 AI。首期只支持通过身份、版本、角色和完整结构校验的 Android SDK 临时目录、模拟器依赖及 WeGame 临时目录。仅共享受控软件标识、目录角色、适用版本、粗粒度结构和结构化用途/建议；完整路径、用户名、自定义文件名、文件正文、API Key 和原始自由文本说明保留在本机。

不共享清单覆盖目录、子内容及父摘要中的相关结构。修改范围会暂停，重新预览并保存后才开启。贡献可查看、单项或全部撤回；停用只停止今后使用，已上传内容可另行撤回。管理凭据用当前 Windows 账户加密，可显式导出恢复文件，需自行妥善保管。更换服务不会沿用旧服务的同意或凭据，旧本机隔离测试文档保留。

至少 5 个符合条件的安装标识、72 小时观察及一致性校验才可能形成共识；安装标识不代表独立真人，也不保证结论正确。共享结果不会自动变成个人成功缓存或投票。结果会标明来源，并提供个人 AI 重新分析入口。

## 个人 AI 与缓存

AI 分析由用户主动启动，向自行配置的模型服务发送文件元数据，服务商按其规则收费。自动刷新不会自动发起付费分析。支持分析扫描根目录或当前目录、进度、用时、取消及实际 API Token 用量。

个人缓存按原始分析时间保留 30 天，命中不续期；最多 20,000 条或 32 MiB，完整请求上下文参与失效。相同并发请求会合并、按实际请求归属费用；设置提供占用查询与清理，清理个人缓存不撤回共享贡献。

文件外部变更会合并同步，无权限或断开的目录保留原记录。应用打开后会检查官网版本信息，不会自动下载安装，可关闭或忽略某一版本。

**AI 与共享经验仅供参考。删除前请确认用途并备份重要数据；应用不会自动删除文件，移入回收站仍需用户确认。**

## 卸载与版权

可通过 Windows 应用列表或安装目录卸载。只移除安装的程序、快捷方式与卸载记录，不删除用户数据。DiskLens 当前暂时闭源，见 `NOTICE.md`；第三方组件许可见 `THIRD-PARTY-NOTICES.txt`。
